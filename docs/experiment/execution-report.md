# ZB202 人数、CO₂ 预测与控制方案执行简报

**阶段：**第一阶段仿真原型（2026-09-29）｜**代码：**`feat/occupancy-co2-control-simulator`，原仓库草稿 PR #3。

## 已完成

项目新增可复现的 0–10 人模拟场景、基于模拟训练日的时变马尔可夫人数预测、单区 CO₂ 质量守恒模型，以及每 5 分钟滚动更新的通风建议。独立实验页比较固定通风、按当前人数响应、预测控制三种策略，并提供曲线和 CSV 导出。当前只计算建议风量，**不会向现场 VAV/BMS 下发指令**。

## 仿真输入与结果

20 个评价日的人员轨迹均为模拟生成；训练用的 120 个模拟日与评价日分开。室外 CO₂ 暂定 420 ppm，初始 CO₂ 默认为 600 ppm，有效室外风量候选为 100–600 m³/h，800 ppm 为实验目标。这些风量**不是**现场 VAV 实测值或批准的设定值。

| 策略 | 占用时超过 800 ppm（20 日平均） | 累计室外空气量（20 日平均） |
| --- | ---: | ---: |
| 固定通风 | 22.3 min/日 | 7,200 m³/日 |
| 当前人数响应 | 0 min/日 | 3,989 m³/日 |
| 预测控制 | 41.5 min/日 | 2,890.5 m³/日 |

在当前权重和假设下，预测控制减少了风量代理值，但占用期间的 CO₂ 表现不如响应策略。累计风量不是实测能耗；这些数字也不是 ZB202 的现场效果。

## 下一步与现场控制条件

先取得独立 VAV 的风量设定值、实测值、上下限、运行/故障状态，以及 AHU 新风比例或室外新风测点的历史趋势。然后用**真实 IoT CO₂ 时间序列 + 同期 BMS 风量**辨识并检验 CO₂ 模型；确认实验许可和回退方式后，先运行只读建议模式，再考虑限幅现场控制。若没有同期风量和真实人数，不能可靠评估现场 CO₂ 预测精度或节能率。
